# VeryonixOS

### A new operating system. Built from the ground up.

VeryonixOS is an independent operating system project focused on building a custom kernel, desktop environment, native applications, and a modern computing experience.

We're building something of our own — one component at a time.

**Created by [Veryonix](https://github.com/Veryonix)**

---

## 🚀 Project Vision

Our goal is to create a fully independent operating system with:

- A custom kernel
- A modern graphical desktop environment
- Native applications and system utilities
- A custom filesystem
- Networking support
- A built-in terminal
- An application and package management system
- An integrated AI assistant

VeryonixOS is being developed as an open-source project, with the goal of welcoming developers, designers, testers, and enthusiasts.

## 🛠️ Technology

The initial development stack is planned to include:

- C and C++ — system development
- x86-64 Assembly — low-level programming
- Limine — bootloader
- QEMU — virtual machine testing
- Git and GitHub — source control and collaboration

## 🗺️ Roadmap

**Phase 1 — Foundations**
- Set up the repository
- Configure the build environment
- Boot a minimal kernel in QEMU

**Phase 2 — Core OS**
- Basic memory management
- Interrupt handling
- Kernel services
- Initial drivers

**Phase 3 — User Experience**
- Graphical interface
- Terminal
- Native applications

**Phase 4 — Expansion**
- Networking

- Package manager
